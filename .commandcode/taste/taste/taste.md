# Taste
- Prefers the agent to maintain persistent project memory as simple markdown files (project overview, task log, notes/decisions), updated after each completed task and read at the start of each session. Confidence: 0.9
- Values simplicity in memory/docs files — keep them concise rather than elaborate. Confidence: 0.8
- Prefers using /find-skills (the skills CLI) to discover and install relevant skills before starting a project, to improve delivery. Confidence: 0.9
- Prefers incremental delivery: stop after each completed, logically testable task and let the user verify/test before proceeding. Confidence: 0.9
- Wants work structured as milestones → phases → tasks, with each task broken down to maximize robustness and scalability. Confidence: 0.8
- Values honest, candid assessment over agreement — explicitly asks to be told if something seems off. Confidence: 0.9
- Prefers explicit constraint/rules documentation (what to do AND what NOT to do) in addition to task tracking, so the agent remembers boundaries across sessions. Confidence: 0.8
- Works in a Windows environment with Command Prompt (cmd) as the shell; project-local CLIs (e.g. Tauri) are not on PATH, so prefer `npx`/local binaries over assuming global installs. Confidence: 0.7
